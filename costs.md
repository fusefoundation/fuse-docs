# Costs and fees

You can read public FUSE data without paying FUSE or signing in. If you want to register a website and earn an operator share, the interface requires a **100 ckUSDT refundable bond**, domain verification, and activation. The bond is not a monthly subscription.

| Item                           | What to expect                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Public read-only integration   | No FUSE registration, bond, or wallet needed. Your own hosting may still cost money.                     |
| Interface activation           | A 100 ckUSDT refundable bond. Ledger fees for approval and funding are separate.                         |
| Participant transfers          | The ckUSDT ledger charges a transfer fee. Read the current fee and show it before the participant signs. |
| Operator payout or bond refund | Check the dashboard for eligibility, the recipient, the ledger fee, and the amount received.             |

## When can I recover the bond?

The interface dashboard tracks eligibility. To recover the bond while keeping the site active, the dashboard must show at least 100 ckUSDT in confirmed original deposits attributed to the site. If you close the site, closure takes effect after seven days; you can then request recovery of any bond still held. The refund goes to the original controller account, less the ledger fee. See the [operator registration guide](register.md#8-track-earnings-and-the-bond).

## What can the operator earn?

On eligible real daily contributions attributed to the site, the operator receives **40% of the protocol fee**, equivalent to **4% of those contributions**. A wallet top-up does not itself earn a commission. See the [worked example](earnings.md).
