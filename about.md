# About FUSE

FUSE is a charity-focused lottery protocol on the Internet Computer. It tracks participation, publishes round results, and maintains a charity reserve. Anyone can view public results in the [FUSE app](https://app.fuseprotocol.org/app) without connecting a wallet.

## What you can verify

- **Rounds:** The public app shows completed rounds and their results. A forecast for the next round is not a final result.
- **Charity:** A share of the protocol fee goes to a separate charity reserve. The public app shows the reserve, published goals, and confirmed transfers when available. Money in the reserve is not the same as money already sent to recipients.
- **Integration:** The [FUSE Interface Kit](https://github.com/burzhuy3/fuse-interface-kit) publishes the Candid contract, JavaScript examples, and test cases for independent developers.

## One protocol, different websites

An independent interface is a website built and operated by a third party. It can display FUSE data and, after registration, help participants use their own wallets. FUSE Root records attribution and publishes results. The ckUSDT ledger records the transfers. An independent interface does not run a separate draw.

You can start with a results page and no wallet integration. If you decide to operate a registered interface, review the [costs and fees](costs.md) before connecting your domain.
