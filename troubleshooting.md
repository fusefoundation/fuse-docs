# Troubleshooting

| Symptom | First check |
| --- | --- |
| Domain verification fails | Request the exact HTTPS verification URL. It should return HTTP 200 without a redirect, login prompt, or HTML app shell. Check the current claim's file, not an older copy. |
| My site is not active | Check each activation requirement in the cabinet: the exact domain, its proof, and the confirmed bond. |
| A published round is missing | Cross-check its cycle ID in the official app. Treat an unavailable result differently from a round with zero payouts. |
| A top-up is not reflected in my earnings | A top-up is not a daily contribution. Check whether a contribution has been used and was attributed to your active interface. |
| A wallet confirmation timed out | Check the original operation or transfer before attempting another one. |

Ask in the [FUSE community](https://t.me/fuseprotocol_en) for general help. For a site-specific case, contact [partners@fuseprotocol.org](mailto:partners@fuseprotocol.org). Share the domain, interface ID if available, and exact error. Never share a seed phrase, private key, wallet session, or sign-in code.
