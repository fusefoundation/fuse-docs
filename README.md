# Build an independent FUSE interface

An independent interface is your own website for people who use FUSE. You decide how to present the project and its results. FUSE records participation, calculates rounds and tracks payouts on ICP.

Start with public round data. You can evaluate the integration before registering a domain, connecting a wallet or putting up a bond.

1. [Quick start](quickstart.md): see what a read-only integration looks like.
2. [Register your website](register.md): understand the domain check, bond and activation.
3. [Operator earnings](earnings.md): see what earns a share and how it is calculated.
4. [Read-only API](api.md): start with the minimum methods for a results page.
5. [Integration kit and Codex skill](integration-kit.md): get the bindings and examples.
6. [Troubleshooting](troubleshooting.md): isolate registration or data issues.
